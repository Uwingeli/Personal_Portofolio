# Personal Portfolio

Hey, I'm Uwingeli Romeo — this is my personal portfolio website.

## What this is

A one-page site that shows who I am, what I can build, and how to reach me.
It's got a hero intro, a quick stats section, a skills breakdown, and a
contact section — all on a dark, violet-and-coral themed design.

## What I used to build it

- **React + TypeScript** — for the actual page and components
- **Vite** — fast dev server and build tool
- **Tailwind CSS v4** — for styling, no separate config file needed
- **shadcn/ui** — pre-built, customizable UI pieces (buttons, cards, etc.)
